## Question 1: File Cipher

The `cipher.py` program:

- Reads text from `raw_text.txt`
- Encrypts the text using two non-negative shift values
- Writes the encrypted text to `encrypted_text.txt`
- Decrypts the encrypted text into `decrypted_text.txt`
- Checks whether the original and decrypted files are identical

Run the program with:

```powershell
python cipher.py
```

## Question 2: Expression Evaluator

The `evaluator.py` program:

- Reads one mathematical expression per line from `input.txt`
- Tokenises each expression
- Uses recursive-descent parsing
- Creates a parse tree
- Calculates the result
- Writes the results to `output.txt`

Run the program with:

```powershell
python evaluator.py
```

## Files

- `cipher.py` – encryption, decryption and verification program
- `evaluator.py` – mathematical expression evaluator
- `raw_text.txt` – original text
- `encrypted_text.txt` – encrypted text
- `decrypted_text.txt` – decrypted text
- `input.txt` – mathematical expressions
- `output.txt` – evaluator results
- `github_link.txt` – public GitHub repository link
